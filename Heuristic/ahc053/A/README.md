# AHC053

## Setup
1. Download official tools from the contest page and place them in `tools/`.
2. `cd tools` and run `cargo build --release`.
3. Use `make` to build the solver.
4. Use `make test` to run tests.

## Directory Structure
- `src/`: Source code
- `tools/`: Official tools (vis, gen)
- `scripts/`: Helper scripts
- `testcases/`: Input/Output for tests
