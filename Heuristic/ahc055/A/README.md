# AHC055

## Directory Structure

```
.
├── src/                    # Source code
│   ├── main.cpp           # Main submission (final version)
│   └── experimental/      # Experimental versions
│       ├── v1.cpp
│       ├── v2.cpp
│       └── template.cpp
│
├── tools/                  # Official tools (Rust)
├── testcases/             # Test cases
│   └── in/                # Input files
├── scripts/               # Utility scripts
│   ├── compare.sh         # Compare script
│   ├── compare_solvers.py
│   ├── optimize_params.py # Parameter optimization (Optuna)
│   └── tune.py
│
├── build/                 # Build artifacts (gitignored)
├── tmp/                   # Temporary files (gitignored)
├── Makefile              # Build configuration
└── README.md
```

## Quick Start

```bash
# Build main solver
make

# Run with sample input using official visualizer
make vis
# -> Opens tools/vis.html in browser

# Generate test cases (requires tools built)
make gen

# Run basic tests (using scripts/compare.sh)
make test

# Run fast test on seeds 0-9 with official scorer
make fast-test

# Clean build artifacts
make clean
```

## Parameter Optimization

Uses Optuna to tune hyperparameters.

```bash
# 1. Activate virtual environment
source /Users/kitamuratatuki/Atcoder/venv/bin/activate

# 2. Run optimization script
python scripts/optimize_params.py
```

## Directory Structure Details

- **src/**: C++ source codes. `main.cpp` is the submission file.
- **tools/**: Official Rust tools. Used for input generation (`gen`) and visualization (`vis`).
- **testcases/**: Inputs generated by `gen`.
- **tmp/**: Temporary files for execution and comparison.
