# Fixstars 高速化コンテスト 2026: 最強パーティ結成！ 問題概要

## 1. 問題の概要
与えられた冒険者の中から、特定の条件を満たす「最強のパーティ」を選び出し、その総パラメータ和を最大化する**最適化問題（最大重みクリーク問題の派生）**です。

## 2. 選出するパーティの条件（必須要件）
1. **全員が互いに友人であること**
   - グラフ理論における**クリーク（完全部分グラフ）**を形成する必要があります。
2. **128種類の全パラメータがBOSSの要求値を上回ること**
   - 選んだメンバーの各能力値の合計が、BOSSの指定する要求値（128次元すべて）以上でなければなりません。

## 3. スコア・目的
- 上記の条件を満たすパーティの中で、**「全メンバーの全128種類のパラメータの総和（総パラメータ和 $T$）」を最大化**することが目的です。
- ※テストケースには必ず条件を満たす解が存在し、かつ最適解は1つに定まるよう生成されています。

## 4. 制約とテストケース
- **冒険者の数 ($N$)**: 
  - `Small`: $N = 24$
  - `Large`: $N = 64$
- **友人関係**: 非常に密なグラフ（確率 $p=0.95$ で友人関係になるようランダム生成）。
- **能力値 ($v_{i,k}$)**: 各冒険者につき128種類あり、それぞれ $1 \sim 100,000$。
- **BOSSの要求値 ($r_k$)**: 
  - `Small`: 最大 700,000
  - `Large`: 最大 1,600,000

## 5. 実装・実行環境のルール
- **実装対象**: `src/solve.cpp` 内の `solve(const input_t &input, output_t &output)` 関数。
- **実行時間制限**: 3秒（プログラムのメモリ制約は 4 GiB）。ビルド時間は3分以内。
- **実行環境**: `g++ 14.1.0` を使用。最適化オプションは `-O2`。
- **並列化**: **OpenMPが使用可能**。CPUは4コア8スレッドが割り当てられます。
- **SIMD**: AVX512をはじめとする各種SIMD命令セットが利用可能です。
