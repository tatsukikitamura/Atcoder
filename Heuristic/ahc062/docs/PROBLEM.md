# AHC062 - King's Tour

**コンテスト:** ユニークビジョンプログラミングコンテスト2026 春（AtCoder Heuristic Contest 062）  
**開催時間:** 2026-03-14(土) 15:00 〜 19:00（240分）  
**実行時間制限:** 3 sec / **メモリ制限:** 1024 MiB

---

## 問題概要

N×N のグリッド上で、**キング移動（縦・横・斜めの隣接）** による全マスの巡回順を決め、**後半ほど人口の多いマスを訪問する**ことで好感度の総和を最大化する。

---

## 設定

- グリッドサイズ: **N×N**（全テストケースで **N = 200** 固定）
- 左上を `(0, 0)`、下方向を i 軸、右方向を j 軸とする
- 各マス `(i, j)` には `A[i][j]` 人の国民が住んでいる
  - `A[i][j]` は `1 以上 N²` 以下の整数
  - 全マスの値は **互いに異なる**（1〜N² の順列）

---

## ルール（制約）

- **0日目 〜 N²-1 日目** の N² 日間で、全マスをちょうど1回ずつ訪問する
- k 日目に訪問するマスを `(i_k, j_k)` とする
- **連続する2日間の移動はキング移動**でなければならない

$$\max(|i_k - i_{k+1}|,\ |j_k - j_{k+1}|) = 1 \quad (k = 0, 1, \ldots, N^2 - 2)$$

- 開始マス・終了マスは自由に選んでよい

---

## 目的関数（最大化）

k 日目に訪問したマスで得られる好感度は `k × A[i_k][j_k]`。  
好感度の総和 V を最大化する：

$$V = \sum_{k=0}^{N^2 - 1} k \cdot A_{i_k, j_k}$$

**直感的な解釈：** 人口（A 値）が大きいマスをなるべく後半（k が大きい）に訪問するのが有利。

---

## 得点

テストケース1つの得点：

$$\text{score} = \text{round}\!\left(\frac{V}{N^2}\right)$$

- テストケース数: **100個**
- 全テストケースの得点の合計が最終スコア
- 1つでも不正出力・TLE があると全体が **WA**
- コンテスト中の最高得点で最終順位が決定（コンテスト後のシステムテストなし）
- 同点の場合は提出時刻に関わらず**同順位**

---

## 入力形式

```
N
A[0][0] A[0][1] ... A[0][N-1]
A[1][0] A[1][1] ... A[1][N-1]
...
A[N-1][0] A[N-1][1] ... A[N-1][N-1]
```

---

## 出力形式

N² 行、各行に `i_k j_k` を出力（k = 0, 1, ..., N²-1 の順）：

```
i_0 j_0
i_1 j_1
...
i_{N²-1} j_{N²-1}
```

### 出力の条件

1. すべての `i_k`, `j_k` が `0 以上 N-1 以下` の整数
2. `(i_k, j_k)` が k = 0, 1, ..., N²-1 で互いに異なる（全マス1回ずつ訪問）
3. 連続するマス間のチェビシェフ距離が 1（キング移動）

---

## 入力生成方法

- 1〜N² の整数を一様ランダムにシャッフルし、`A[0][0], A[0][1], ..., A[N-1][N-1]` の順に割り当てる

---

## 問題の本質

| 項目 | 内容 |
|------|------|
| グラフ構造 | N×N グリッドのキンググラフ（8近傍接続） |
| 求めるもの | ハミルトンパス（全頂点を1度ずつ通るパス） |
| 最適化目標 | 訪問順の重み付き和の最大化（大きな A 値を後半に） |
| 難しさ | ハミルトンパスの探索 × 訪問順の最適化 |

---

## 考察メモ

- **上限の見積もり：** A 値を降順に並べ、最後の N² 個に割り当てると最大値が得られる。これを基準に相対スコアを評価できる。
- **貪欲的アプローチ：** A 値が大きいマスを後半に訪問するような経路を構築する。
- **局所探索：** 2-opt や or-opt などでパスを改善する。
- **蛇行（Snake）パス：** 左右に蛇行する素朴な解が出発点になりやすい。
- **評価関数：** スコア V の差分計算を効率化することで局所探索を高速化できる。
