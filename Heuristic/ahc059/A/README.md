# AHC059 Post-mortem: 78th Place Success Analysis

今日一日、本当にお疲れ様でした！そして78位という素晴らしい結果、本当におめでとうございます。
これまでの全15回以上のやり取りを振り返り、何が勝因だったのかを分析してまとめました。

## 📊 Result
- **Rank:** 78th
- **Strategy:** 3-Phase Simulated Annealing (Grouping -> Ordering -> Routing)

## 🚀 技術的進化のタイムライン

### 1. 「近接性」への着目 (Proximity Grouping)
- **内容:** 単純な欲張り法から、スタート地点やゴール地点が近いカードを「グループ」としてまとめる設計に転換しました。
- **勝因:** 「無駄な移動」を減らすための土台ができ、後のSA（焼きなまし法）の探索空間を適切に絞り込むことができました。

### 2. 3フェーズSAの構築
- **Phase 1 (Grouping):** どのカードを一緒に運ぶか。
- **Phase 2 (Ordering):** グループ内での回収・配達順序はどうするか。
- **Phase 3 (Routing):** グループ間の移動（マクロルート）はどうするか。
- **勝因:** 問題を「マクロ」と「ミクロ」に分離したことで、計算資源を効率的に使えました。

### 3. パスルーティングの柔軟化 (Flexible Path)
- **内容:** 直角なL字パスだけでなく、途中に「遊び」を持たせたクランク型のパスを許容しました。
- **勝因:** これにより、他カードのパスに「相乗り」できる機会が劇的に増え、スコアが大きく改善しました。

### 4. SA遷移の強化 (Merge & Split)
- **内容:** グループの「移動」や「入れ替え」だけでなく、グループ同士を「結合」したり「分割」したりする操作をSAに追加しました。
- **勝因:** 部分最適なグループ構成から抜け出し、より大きな「一筆書き」に近い効率的なグループを発見できるようになりました。

### 5. コスト関数と時間配分の微調整
- **内容:** グループ化の失敗に対して「一律ペナルティ」ではなく「距離に応じたコスト」を導入し、またPhase 1（Grouping）の時間を長く確保しました。
- **勝因:** SAが「惜しい解」を捨てずに改善していけるようになり、探索の質が向上しました。

## 💡 成功の核心
今回の成功の核心は、**「パスを固定せず、柔軟に曲げることでマージの機会を増やしたこと」**と、**「それを評価できる3段階のSA構造を構築したこと」**にあると思います。

特に、後半で行った「Merge/Split遷移の追加」と「Phase 1の時間延長」が、最後のスコアの伸びを支えた決定打になりましたね。

### アルゴリズム詳細

#### 1. Softmax（ボルツマン）選択
```cpp
// コスト差に基づく重み計算
weights[i] = exp(-(candidates[i].cost - min_cost) / T);

// 累積確率で選択
double r = uniform_real_distribution<double>(0, sum_weights)(rng);
```
- 固定確率ではなく、**コストに応じた連続的な確率分布**で候補を選択
- 温度T=1.5で適度な探索と収束のバランスを実現

#### 2. 入れ子グループ化 (Proximity Grouping)
```cpp
// 挿入コスト = 寄り道による追加距離
insertion_cost = dist(A,C) + dist(D,B) - dist(A,B)
```
- メインカードの経路上に別のカードを「入れ子」にできるか判定
- 挿入コストが閾値(≤1)以下なら入れ子に追加
- 往路→復路のネスト構造で複数カードを一度に処理

#### 3. 多スタート貪欲法
```cpp
while (!timer.is_over()) {
    run_iteration(deterministic);  // 1つの完全な解を構築
    if (move_count < best_move_count) {
        // ベスト更新
    }
}
```
- 時間いっぱい何度も解を再構築
- 初回のみ決定的（純粋Greedy）、以後はsoftmax選択でランダム性を導入
