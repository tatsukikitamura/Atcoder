# AHC059 A - Stack to Match Pairs 解法まとめ

## 結果

🏆 **78位 / 700人参加** (上位11%)  
📈 **Performance: 2128** (黄色パフォーマンス)

## 問題の要点

- 20×20の盤面上に200種類×2枚=400枚のカードが配置
- (0,0)からスタートし、カードを取ってスタック(山札)に積む
- **同じ番号のカード2枚を連続で積むとペアが消える**
- 全カードを消すまでの**移動回数を最小化**

## 実装の概要

### 2フェーズ構成

| フェーズ | 時間配分 | 内容 |
|---------|---------|------|
| Phase1 | 0〜1.5秒 | 貪欲法ベースで複数解を構築 |
| Phase2 | 1.5〜1.95秒 | 焼きなまし法(SA)で改良 |

### Phase1: グループ構築による貪欲法

#### 核となるアイデア: 「グループ化」

スタックの性質（LIFO）を活用し、**複数のペアをまとめて処理**する。

```
例: グループ [A, B, C] の場合
往路: A₁ → B₁ → C₁ (1枚目を順番に取る)
復路: C₂ → B₂ → A₂ (2枚目を逆順で取る)

結果: スタックにはA,B,C,C,B,Aの順で積まれ、全てのペアが消える
```

#### なぜグループ化が有効か

1. **経路の再利用**: 往路と復路で同じ経路の一部を共有できる
2. **挿入コストの最小化**: グループ内に「通り道」にあるカードを追加することで移動コストを抑える

#### 具体的な構築アルゴリズム

```cpp
// find_proximity_group関数のロジック
1. 現在位置から最も近いカードをメインカードとして選択
2. そのペア(2枚)の間に「挿入コスト≤1」で入るカードを探索
3. 挿入コスト = (現在位置→新カード1枚目) + (新カード1枚目→2枚目) + (新カード2枚目→元の終点)
             - (現在位置→元の終点) - (新カード1枚目→2枚目)
4. コストが低いカードを最大200枚までグループに追加
```

### Phase2: 焼きなまし法による改良

2種類の近傍操作を使用:

| 操作 | 内容 |
|-----|------|
| CardMove | あるカードを別グループに移動 |
| FlipVisit | 1枚のカードの訪問順序を反転 |

> [!NOTE]
> 実験により、グループ単位の操作（隣接swap、任意swap、グループ反転）はほぼ改善に寄与しないことが判明したため、カード単位の操作のみを採用。

**差分計算**により高速化: 変更箇所以降のみ再計算

## この問題に刺さった理由

### 1. スタック制約との相性

> **LIFO制約 = 「ネスト構造」が最適**

通常の巡回セールスマン問題と異なり、この問題では**入れ子構造（往路→復路）**が強制される。グループ化はこの制約を積極的に活用している。

### 2. 盤面のランダム性

問題文より:
> カードの初期配置は N² 枚のカードをランダムな順に並び替えることで生成

ランダム配置では、**近くにペアがある確率が低い**。
→ 単純に「近いペアから消す」だけでは効率が悪い
→ グループ化で「ついでに取れるカード」を活用することで大幅に効率化

### 3. 挿入コストの閾値設計

```cpp
if (best_inner != -1 && min_insertion_cost <= 1) {
    group.push_back({best_inner, best_inner_visit_first});
```

**挿入コスト ≤ 1** という閾値が絶妙:
- コスト0: 完全に「通り道」にある → 追加コストなし
- コスト1: ほぼ通り道、1マスだけ寄り道 → 許容範囲
- コスト2以上: 寄り道が大きすぎる → 別グループにした方が良い

### 4. SAの近傍操作の多様性

5種類の操作により**異なる粒度での最適化**が可能:
- グループ単位の改善 (swap, 反転)
- カード単位の微調整 (移動, 向き反転)

これにより局所解に陥りにくく、幅広い解空間を探索できる。

## パフォーマンス指標

```
Phase1: ~1000回のイテレーションで初期解を複数生成
Phase2: ~100,000回のSAイテレーションで改良
```

## まとめ

この解法が有効だった理由:

1. **スタック制約の活用**: ネストしたグループ構造でLIFO制約を自然に満たす
2. **貪欲法の品質**: 挿入コストベースのグループ構築で良質な初期解を生成
3. **差分計算の高速化**: SAの各イテレーションを高速に処理
4. **多様な近傍**: グループ/カード両レベルでの改善が可能
