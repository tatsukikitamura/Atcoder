**講義タイトル：学術研究における公正と責任ある研究活動**
**担当教員：札野 順（大学総合研究センター）**

本講義では、研究倫理の基本概念と責任ある研究活動の重要性について学んだ。研究倫理とは、新たな知識を生み出す活動に従事する者が、社会や他の研究者に対して行う行為の善悪を判断する基準だという。
講義の冒頭で驚いたのは、2000年以降に論文撤回数が急増しているというデータだ。特に日本は深刻で、撤回論文数のランキングに複数の日本人が名を連ねているという。この話を聞いて、私自身の経験を思い出した。以前のレポート作成時、参考文献の記載を忘れて指摘を受けたことがある。当時は単なるミスだと思っていたが、これが盗用に該当しうることを本講義で知り、衝撃を受けた。研究不正は他者への危害、時間と費用の浪費、そして科学への信頼崩壊につながる。決して他人事ではないと感じた。
講義で最も印象に残ったのは、「予防倫理」と「志向倫理」の対比だ。予防倫理は「やってはいけないこと」を示すネガティブな倫理、志向倫理は「より善い行動」へ導くポジティブな倫理である。特に興味深かったのが、ポジティブ心理学を取り入れた「科学技術倫理2.0」という考え方だ。セリグマンの研究によると、自分より大きなもののために貢献することが、最も持続的な幸福感をもたらすという。
この講義を通じて、研究倫理は単なる規制ではなく、研究者自身の幸福にも直結するのだと気づいた。「成功するから幸せになる」のではなく「幸せだから成功する」という話は、研究への向き合い方を考え直すきっかけになった。倫理的に研究することは、社会のためだけでなく、自分自身のためでもある。この視点を今後の指針にしたい。

早稲田大学学術研究倫理憲章を読み、まず目に留まったのは「人類の福祉と世界平和に貢献する」という一文だった。正直なところ、最初は大きすぎる目標に感じた。しかし講義で学んだ内容と照らし合わせると、これは決して遠い話ではないと気づいた。
講義では、科学技術倫理の基本原則として「公衆の安全、健康、福利への貢献」が挙げられていた。憲章第1条の理念とまさに重なる。私が先述したレポートでの失敗も、小さなミスが信頼を損なう第一歩になりうるという点で、この原則に反する行為だったと今では理解している。
また、講義で紹介されたNational Academiesの6つの価値—客観性、正直さ、公開性など—を見たとき、当たり前のことばかりだと感じた。しかし、疑わしい研究行為が10〜50%の研究者に見られるという事実を知り、「当たり前」を守り続けることの難しさを痛感した。
研究を通じて目指すべきものは何か。私は、社会への貢献と自分自身の充実感の両立だと考える。ポジティブ心理学が示すように、自分より大きなもののために働くことが幸福につながるなら、倫理的な研究は義務ではなく、研究者自身にとっても意味のある選択となる。
